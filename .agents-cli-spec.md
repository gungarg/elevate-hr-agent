# Agent Specification: HR Multi-Agent Assistant (ADK 2.0 - OKF Edition)

## Overview
- **Name:** hr-agentic-assistant
- **Description:** Enterprise HR Multi-Agent Virtual Assistant orchestrating WorkWeek HCM operations, ServiceImmediately ITSM incident management, and grounded HR Policy Q&A via Open Knowledge Format (OKF).
- **Framework:** Google Agent Development Kit (ADK 2.0)
- **Deployment Target:** Vertex AI Agent Engine (`agent_runtime`)
- **Model:** `gemini-3.5-flash`
- **Knowledge Layer:** Open Knowledge Format (OKF) Bundle (`knowledge/`)
- **Security & Inspection:** Google Cloud Model Armor with Sensitive Data Protection (SDP)

---

## Agent Topology & Tools

### 1. Root Orchestrator: `concierge_agent`
- **Class:** `google.adk.agents.Agent`
- **Model:** `gemini-3.5-flash`
- **Direct Tools:**
  - `list_concepts`: Scans YAML frontmatter in `knowledge/` bundle to discover concepts.
  - `read_concept`: Parses full markdown concept file with exact footnote citations.
- **Sub-agents (`mode="task"`):**
  - `workweek_specialist`
  - `itsm_specialist`
- **Security Hooks:** Google Cloud Model Armor user prompt & response sanitization templates via ADK callbacks (`before_agent_callback`, `after_agent_callback`).
- **Session Management:** `VertexAiSessionService` for managed multi-turn state.

---

### 2. Specialist: `workweek_specialist`
- **Class:** `google.adk.agents.Agent` (ADK 2.0 `mode="task"`)
- **Model:** `gemini-3.5-flash`
- **Output Schema:** `WorkWeekTaskOutput` (Pydantic Model)
- **Tools:**
  - `workweek_mcp`: `McpToolset` connected to `https://mock-saas.aishprabhat.demo.altostrat.com/work-week/mcp/`
  - `list_concepts`, `read_concept`: Optional OKF tools for autonomous leave policy threshold checks.
- **Headers:** `{"X-MCP-Token": "<SECRET_MCP_TOKEN>"}`
- **FastMCP Tools Covered (7/7):**
  - `get_current_employee_id()`
  - `get_personal_info(employee_id)`
  - `update_personal_info(employee_id, address, phone)`
  - `get_employee_balances(employee_id)`
  - `request_time_off(employee_id, start_date, end_date, leave_type, days)`
  - `get_leave_requests(employee_id)`
  - `cancel_leave_request(employee_id, request_id)`
- **FastMCP Resources Covered (2/2):**
  - `workweek://employees/{employee_id}/profile`
  - `workweek://employees/{employee_id}/timeoff`
- **REST Endpoints Supported:**
  - `PUT /work-week/api/employees/{employee_id}/timeoff/requests/{request_id}` (`LeaveRequestUpdateRequest`)
  - `GET /work-week/api/employees/{employee_id}/feedback` (Feedback history)
- **Guardrails:**
  - Balance validation (`requested_days <= remaining_balance`).
  - Chronological date validation (`start_date >= today`, `start_date <= end_date`).
  - Contact regex validation (`address >= 5 chars`, `phone` matching `^\+?[\d\s\-()]{7,20}$`).

### 3. Specialist: `itsm_specialist`
- **Class:** `google.adk.agents.Agent` (ADK 2.0 `mode="task"`)
- **Model:** `gemini-3.5-flash`
- **Output Schema:** `ITSMTaskOutput` (Pydantic Model)
- **Tools:**
  - `serviceimmediately_mcp`: `McpToolset` connected to `https://mock-saas.aishprabhat.demo.altostrat.com/service-immediately/mcp/`
- **Headers:** `{"X-MCP-Token": "<SECRET_MCP_TOKEN>"}`
- **FastMCP Tools Covered (4/4):**
  - `list_tickets(employee_id)`
  - `create_ticket(requested_by, category, short_description, priority, assignment_group='Service Desk')`
  - `add_ticket_comment(ticket_id, author, comment)`
  - `update_ticket_status(ticket_id, status, resolution_notes='', updated_by='System')`
- **FastMCP Resources Covered (1/1):**
  - `serviceimmediately://tickets/{ticket_id}`
- **State Machine Guardrails:**
  - `New -> In Progress/Closed` (Allowed)
  - `In Progress -> Resolved/Closed` (Allowed)
  - `Resolved -> In Progress/Closed` (Allowed)
  - `Closed -> *` (Terminal / Blocked)
  - 5-minute duplicate ticket suppression.
  - Priority 1 ('1 - Critical') outage description validation (`outage`, `crash`, `downtime`, `unusable`).

## Token Lifecycle Administration
- `GET /api/mcp-tokens`: List active PAT tokens.
- `POST /api/mcp-tokens`: Generate Personal Access Token (`TokenGenerationRequest`).
- `DELETE /api/mcp-tokens/{token_id}`: Revoke compromised/rotated tokens.
- `GET /healthz`: Container liveness and startup probe endpoint.
