## 2. Multi-Agent Topology (Standard Conversational Sub-Agents - Option 2)

```python
from google.adk.agents import Agent
from google.adk.tools.mcp_tool import McpToolset
from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPConnectionParams
from google.adk.tools import VertexAiSearchTool

# 1. Semantic Policy Search Tool (Vertex AI Search Enterprise Datastore)
policy_search_tool = VertexAiSearchTool(
    data_store_id="projects/agenticai-gunjan/locations/global/collections/default_collection/dataStores/hr-policy-datastore"
)

# 2. FastMCP Toolsets (Streamable HTTP with X-MCP-Token)
workweek_mcp = McpToolset(
    connection_params=StreamableHTTPConnectionParams(
        url="https://mock-saas.aishprabhat.demo.altostrat.com/work-week/mcp/",
        headers={"X-MCP-Token": "mcp_zYnFTkwwEfKkx6qaHgW2XTiTRzREoiHjwDZR3I64XdA"}
    )
)

serviceimmediately_mcp = McpToolset(
    connection_params=StreamableHTTPConnectionParams(
        url="https://mock-saas.aishprabhat.demo.altostrat.com/service-immediately/mcp/",
        headers={"X-MCP-Token": "mcp_zYnFTkwwEfKkx6qaHgW2XTiTRzREoiHjwDZR3I64XdA"}
    )
)

# 3. Specialist: WorkWeek Agent (Option 2: Autonomous Tool Access)
workweek_specialist = Agent(
    name="workweek_specialist",
    model="gemini-3.5-flash",
    description="Specialist handling employee profile lookups, leave balances, policy validation for time off, and leave bookings.",
    instruction="""You are the WorkWeek HCM specialist. 
When a user requests time off (e.g. sick leave, childcare leave, vacation):
1. First use policy_search_tool to verify policy limits, documentation rules (e.g. Medical Certificates for sick leave >2 days), and notice periods.
2. Check employee leave balances and submit the leave request using workweek_mcp tools.
3. In your response, confirm the booking AND cite any required compliance actions (such as submitting MCs or manager notifications).""",
    tools=[workweek_mcp, policy_search_tool],
)

# 4. Specialist: ITSM Service Desk Agent
itsm_specialist = Agent(
    name="itsm_specialist",
    model="gemini-3.5-flash",
    description="Specialist handling IT helpdesk tickets, incident creation, status updates, and hardware requests in ServiceImmediately.",
    instruction="""You are the ITSM specialist. 
Help the user file tickets, track incident status, and manage IT issues using your ITSM tools.
Enforce the formal lifecycle state machine (New -> In Progress -> Resolved -> Closed).""",
    tools=[serviceimmediately_mcp],
)

# 5. Root Orchestrator: Main Concierge Agent
concierge_agent = Agent(
    name="concierge_agent",
    model="gemini-3.5-flash",
    description="Primary Enterprise HR & IT Concierge Assistant answering company policy questions and routing to specialists.",
    instruction="""You are the primary enterprise concierge.
Answer general policy questions using policy_search_tool.
Delegate HR leave and profile operations to workweek_specialist.
Delegate IT helpdesk and incident requests to itsm_specialist.""",
    tools=[policy_search_tool],
    sub_agents=[workweek_specialist, itsm_specialist],
)

root_agent = concierge_agent
```

## 3. FastMCP Endpoints & Tools

### WorkWeek HCM (`/work-week/mcp/`)
- `get_personal_info(employee_id: str)`
- `update_personal_info(employee_id: str, address: str, phone: str)`
- `get_employee_balances(employee_id: str)`
- `request_time_off(employee_id: str, start_date: str, end_date: str, leave_type: str, days: float)`
- `cancel_leave_request(employee_id: str, request_id: int)`

### ServiceImmediately ITSM (`/service-immediately/mcp/`)
- `list_tickets(employee_id: str)`
- `create_ticket(requested_by: str, category: str, short_description: str, priority: str, assignment_group: str)`
- `add_ticket_comment(ticket_id: str, author: str, comment: str)`
- `update_ticket_status(ticket_id: str, status: str, resolution_notes: str)`
